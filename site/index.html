SpecKit Governance Dashboard

A Markdown-first visual dashboard for repositories created with or compatible with GitHub Spec Kit. Scan artifacts, generate a deterministic derived snapshot, and understand project health without changing the project.

Live demo · View on GitHub · Eslam M. Mohamed

Markdown stays authoritative

Generated JSON is derived cache only. No lifecycle state is written back.

External project support

Point --project-root at any local SpecKit project.

Adapter-based

Use vanilla artifacts or add optional governance conventions.

How it works

CLI → discovery → adapters → normalization → validators → snapshot → UI

There is no database, backend service, or mutable state store.

Visual overview

The public demo uses only fictional Markdown artifacts. Generate the complete screenshot set locally with npm run demo:screenshots.

Quick start

npm install
npm run build
npm run dashboard:generate -- --project-root ./examples/vanilla-speckit-demo --deterministic
npm run dashboard:serve -- --project-root ./examples/vanilla-speckit-demo

Install from npm

After the initial package release, run the dashboard directly against your own local SpecKit project. Repository examples are intentionally not included in the npm package.

npx speckit-governance-dashboard@0.1.0 doctor --project-root ../my-speckit-project
npx speckit-governance-dashboard@0.1.0 generate --project-root ../my-speckit-project --deterministic

npm install --global speckit-governance-dashboard@0.1.0
speckit-dashboard serve --project-root ../my-speckit-project

The dashboard reads the project specified by --project-root and never changes its Markdown or lifecycle state.

Run the full demo

npm run demo:full:generate
npm run demo:full:check
npm run demo:screenshots

The full demo covers contracts, phase exits, coverage, decisions, evidence health, blockers, activity, and artifact inventory.

Privacy and security

Snapshots can contain paths, feature names, and diagnostics. Do not publish a snapshot from a private repository without reviewing and sanitizing it.
