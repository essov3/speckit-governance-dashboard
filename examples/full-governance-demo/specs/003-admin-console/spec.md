# Admin console

- As a reviewer, I can inspect synthetic release readiness.
## Functional requirements
- FR-201: Show gate status and decision dependencies.
## Acceptance scenarios
- SC-201: A reviewer sees pending work without changing it.

## Dependencies
- API contracts and D3 registration model.
## Out of scope
