# API contracts

## User stories
- As an integrator, I can use a documented synthetic public API and webhook events.
## Functional requirements
- FR-101: Publish an OpenAPI document.
- FR-102: Describe webhook payloads.
## Non-functional requirements
- NFR-101: Contract checks are reproducible.
## Acceptance scenarios
- SC-101: Contract validation passes with documented examples.
## Edge cases
- Unknown event types are ignored safely.
## Dependencies
- Platform foundation health contract.
## Out of scope
- Authentication implementation.
