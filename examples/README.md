# Synthetic examples

These projects are fictional and safe to inspect, run, and publish. They demonstrate supported Markdown shapes only; they are not production templates.

- `vanilla-speckit-demo`: a small vanilla SpecKit project that passes the dashboard checks.
- `governance-demo`: a governance-oriented project that intentionally shows a pending decision and missing evidence warning.
- `full-governance-demo`: the public-safe, comprehensive visual demo used for dashboard screenshots.
